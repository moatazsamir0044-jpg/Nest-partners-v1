# Nest Ambassadors — V1 Roadmap

Deliverables from the CCO's referral-programme working session (July 2026), synthesizing the Nest Ambassadors concept deck and the exploratory chat that produced it into a management-ready package.

| File | Purpose |
|---|---|
| [`01-research-report.md`](./01-research-report.md) | Full research: strategic context (vision vs. V1), Nawy Partners / Carofi Partners benchmark analysis, programme mechanics, the CX attribution problem, core reasoning, risks, and success metrics. |
| [`02-quick-win-action-plan.md`](./02-quick-win-action-plan.md) | The feasible, fast execution plan — 3 decisions, a 7-day launch sequence, build specs, ownership matrix, and the Week-4 scale-or-kill gate. |
| [`03-management-presentation.html`](./03-management-presentation.html) | A 15-slide, click-through presentation deck (arrow keys / swipe / on-screen nav) distilling both documents into the key points for a leadership walkthrough. Open the file directly in a browser to present. |
| [`04-department-task-ownership.md`](./04-department-task-ownership.md) | Per-department task assignments: every task with its owning department, deadline on the 7-day clock, "done when" acceptance test, and a blank Owner column to fill with names in the Phase-0 meeting. Includes the cross-department critical path. |
| [`05-task-ownership-sheet.html`](./05-task-ownership-sheet.html) | Printable meeting version of the ownership matrix — open in a browser and print, with owner lines to fill in by hand during the meeting. |

**Context:** BirdNest's CCO wants to build a partner-referral engine similar to Nawy Partners and Carofi Partners. Rather than building that platform first, the agreed approach is to prove the model internally — every employee becomes a paid referrer (**Nest Ambassadors**) across two live revenue tracks, Sahel reservations and furnishing packages — using zero new technology (a Google Form, a tracking sheet, WhatsApp). This is **V1**: a 7-day launch and a 4-week test that either earns incremental revenue this season or produces the exact operating data needed to design the real partner platform (V2/V3).
