Cross-department dependencies — the critical path

  1. L1–L4 block everything. No commissions, no CX decision, no date → no materials, no SOP, no launch.
  2. O3 (codes) needs HR's staff list → feeds M3 (toolkit) → feeds Day-5 distribution.
  3. S3 (fact sheet) feeds M3 (toolkit) — Sales must deliver it by end of Day 4.
  4. O5 (validation SOP) needs L2 (CX decision) — form logic and eligibility comms both wait on it.
  5. M5 (launch) needs L6 (leadership message) — schedule the recording before Day 6, not on it.
